# Demo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate static build (`yarn build:demo`) of the real SPA that runs the real API router and handlers inside the browser against an in-memory store seeded with an invented household, so anyone can try the app with nothing installed and no data leaving the page.

**Architecture:** A Map-backed `MemoryStore` implements the existing `Store` interface and passes the shared contract suite. `src/demo/` holds browser-safe, node-testable logic: an adapter that turns `fetch('/api/...')` calls into the Lambda's API Gateway events and dispatches them to the real router, a seed that replays the screenshot household through the real handlers, and a `fetch` installer. `app/demo/` holds only React glue (banner, start-up). A compile-time flag `VITE_DEMO` removes all of it from every other build, and a CI check proves it.

**Tech Stack:** TypeScript, React Router v7 (SPA mode) + Vite 7, Vitest (node and jsdom projects), the existing Store contract suite, Node scripts (`.cjs`/`.mjs`), optional Playwright for a local browser smoke.

**Spec:** `docs/superpowers/specs/2026-10-17-demo-mode-design.md`

## Plan rulings (deviations from the spec's wording, with reasons)

1. **Modules live under `src/`, not `app/demo/`.** `src/store/memory.ts` and `src/demo/*` hold the logic so it is tested in the fast node project (jsdom lacks a dependable `crypto.randomUUID`, which the handlers use). `app/demo/` has only React glue. Same design, different folders.
2. **Seeding reuses the screenshot fixtures through their public read API**, not by sharing a data module. `scripts/screenshots/fixtures.mjs` is API-response shaped with its own stub handler, so `src/demo/seed.ts` calls `createStore(now).handle('GET', ...)` to read the invented household and **replays it as real requests**. The screenshot harness is not changed. Transaction ids are not preserved (the handlers require UUIDs).
3. **CSP is delivered by the host, generated by the build.** The framework's own inline scripts cannot be allowed by a `<meta>` policy without hashes, so `yarn build:demo` writes `build/demo/csp-header.txt` (a `Content-Security-Policy` value with the inline-script hashes) for the static host to send; the demo page itself carries `noindex`. The "no external origins" guarantee is also checked statically by the build check.
4. **Registration split.** `api-handler.ts` keeps its two push routes; the other routes move to `src/api/routes.ts` so the browser never imports `src/api/push.ts`, which uses Node's `crypto`.

```ts
import { planPatch } from './patch';
import {
  ConditionFailedError, type Item, type Key, type PatchOptions, type QueryOptions, type Store, type TxOp,
} from './types';

type Attributes = Record<string, unknown>;

// A JSON round trip, as the SQLite store does on every write: undefined attributes disappear, nulls stay, and nothing is shared
// with the caller.
function copy<T>(value: T): T {
  return JSON.parse(JSON.stringify(value)) as T;
}

function pick(item: Item, attributes: string[]): Item {
  const picked: Record<string, unknown> = {};
  for (const name of attributes) {
    if (name in item) picked[name] = item[name];
  }
  return picked as Item;
}

// The store the browser demo runs on: everything lives in memory and disappears with the page. It follows the same contract
// as SqliteStore and DynamoStore (see src/store/__tests__/contract.ts).
export class MemoryStore implements Store {
  private readonly partitions = new Map<string, Map<string, Attributes>>();

  async get(key: Key): Promise<Item | undefined> {
    const row = this.rowOf(key);
    return row === undefined ? undefined : this.toItem(key.PK, key.SK, row);
  }

  async put(item: Item, opts: { ifAbsent?: boolean } = {}): Promise<void> {
    if (opts.ifAbsent && this.rowOf(item) !== undefined) throw new ConditionFailedError();
    this.write(item);
  }

  async patch(key: Key, fields: Record<string, unknown>, opts: PatchOptions = {}): Promise<Item> {
    const plan = planPatch(fields, opts.defaults);
    const stored = this.rowOf(key);
    if (stored === undefined && opts.mustExist) throw new ConditionFailedError();

    const current: Attributes = stored ?? {};
    const defaults = plan.defaults.filter(([name]) => current[name] === undefined);
    this.write({ ...Object.fromEntries(defaults), ...current, ...Object.fromEntries(plan.fields), PK: key.PK, SK: key.SK });
    return this.toItem(key.PK, key.SK, this.rowOf(key) as Attributes);
  }

  async delete(key: Key, opts: { ifPresent?: boolean } = {}): Promise<void> {
    if (opts.ifPresent && this.rowOf(key) === undefined) throw new ConditionFailedError();
    this.remove(key);
  }

  async query(pk: string, opts: QueryOptions = {}): Promise<Item[]> {
    if (opts.skPrefix !== undefined && opts.skEquals !== undefined) {
      throw new Error('query takes skPrefix or skEquals, not both');
    }
    const partition = this.partitions.get(pk);
    if (partition === undefined) return [];

    const sortKeys = this.matchingSortKeys(partition, opts);
    const items = sortKeys.map(sk => this.toItem(pk, sk, partition.get(sk) as Attributes));
    const attributes = opts.attributes;
    return attributes?.length ? items.map(item => pick(item, attributes)) : items;
  }

  async transact(ops: TxOp[]): Promise<void> {
    if (ops.length === 0) return;
    const keys = ops.map(op => ('put' in op ? op.put : op.delete));
    const identities = new Set(keys.map(key => `${key.PK}\u0000${key.SK}`));
    if (identities.size !== keys.length) {
      throw new Error('transact cannot touch the same item twice');
    }

    // Every condition is checked against the state before anything is written, so a failure leaves the store untouched.
    ops.forEach((op, index) => {
      if ('put' in op) {
        if (op.ifAbsent && this.rowOf(op.put) !== undefined) throw new ConditionFailedError(index);
        return;
      }
      if (op.ifPresent && this.rowOf(op.delete) === undefined) throw new ConditionFailedError(index);
    });
    for (const op of ops) {
      if ('put' in op) this.write(op.put);
      else this.remove(op.delete);
    }
  }

  private rowOf(key: Key): Attributes | undefined {
    return this.partitions.get(key.PK)?.get(key.SK);
  }

  private write(item: Item): void {
    const { PK, SK, ...attributes } = item;
    let partition = this.partitions.get(PK);
    if (partition === undefined) {
      partition = new Map();
      this.partitions.set(PK, partition);
    }
    partition.set(SK, copy(attributes));
  }

  private remove(key: Key): void {
    this.partitions.get(key.PK)?.delete(key.SK);
  }

  private toItem(pk: string, sk: string, row: Attributes): Item {
    return { ...copy(row), PK: pk, SK: sk } as Item;
  }

  // Ascending by sort key (plain string order, which is also SQLite's order for the ASCII keys this app uses).
  private matchingSortKeys(partition: Map<string, Attributes>, opts: QueryOptions): string[] {
    if (opts.skEquals !== undefined) return partition.has(opts.skEquals) ? [opts.skEquals] : [];
    const prefix = opts.skPrefix ?? '';
    return [...partition.keys()].filter(sk => sk.startsWith(prefix)).sort();
  }
}
```

```ts
import type { APIGatewayProxyEventV2 } from 'aws-lambda';
import { createRouter } from '../api/router';
import { registerCoreRoutes } from '../api/routes';
import { setStore } from '../store';
import { MemoryStore } from '../store/memory';
import { DEMO_MARKER } from './marker';

export const DEMO_USER_ID = 'demo|visitor';
export const DEMO_EMAIL = 'demo@example.com';

export interface DemoRequest {
  method: string;
  url: string;
  headers?: Record<string, string>;
  body?: string;
}

export interface DemoResponse {
  status: number;
  headers: Record<string, string>;
  body: string;
}

export type Send = (method: string, path: string, body?: unknown) => Promise<DemoResponse>;

export interface DemoApi {
  handles(pathname: string): boolean;
  handle(request: DemoRequest): Promise<DemoResponse>;
  send: Send;
  reset(): Promise<void>;
}

export interface DemoApiOptions {
  // Fills a fresh store through the API, once at start-up and again on every reset.
  seed?: (send: Send) => Promise<void>;
}

const BASE = 'http://demo.invalid';

function reply(status: number, body: object): DemoResponse {
  return { status, headers: { 'Content-Type': 'application/json', 'X-Demo': DEMO_MARKER }, body: JSON.stringify(body) };
}

// The sign-in endpoints of the built-in login, answered locally: the visitor is always signed in, so the sign-in form never shows.
function authReply(method: string, path: string): DemoResponse {
  if (method === 'GET' && path === '/api/auth/me') return reply(200, { userId: DEMO_USER_ID, email: DEMO_EMAIL });
  if (method === 'GET' && path === '/api/auth/status') return reply(200, { setupRequired: false, recoveryOpen: false });
  if (method === 'POST' && (path === '/api/auth/login' || path === '/api/auth/setup')) {
    return reply(200, { userId: DEMO_USER_ID, email: DEMO_EMAIL });
  }
  if (method === 'POST' && path === '/api/auth/logout') return reply(200, {});
  return reply(404, { error: 'Endpoint not found' });
}

// The same shape the Lambda receives from API Gateway, which is what every handler reads.
function buildEvent(request: DemoRequest, target: URL): APIGatewayProxyEventV2 {
  const headers = Object.fromEntries(Object.entries(request.headers ?? {}).map(([name, value]) => [name.toLowerCase(), value]));
  const query: Record<string, string> = {};
  target.searchParams.forEach((value, name) => { query[name] = value; });
  const routeKey = `${request.method} /api/{proxy+}`;
  return {
    version: '2.0',
    routeKey,
    rawPath: target.pathname,
    rawQueryString: target.search.slice(1),
    headers,
    queryStringParameters: Object.keys(query).length > 0 ? query : undefined,
    body: request.body,
    isBase64Encoded: false,
    requestContext: {
      routeKey,
      http: { method: request.method, path: '/api/{proxy+}', protocol: 'HTTP/1.1', sourceIp: '127.0.0.1', userAgent: headers['user-agent'] ?? '' },
    },
  } as unknown as APIGatewayProxyEventV2;
}

export async function createDemoApi(options: DemoApiOptions = {}): Promise<DemoApi> {
  const router = createRouter();
  registerCoreRoutes(router);

  async function handle(request: DemoRequest): Promise<DemoResponse> {
    const target = new URL(request.url, BASE);
    const path = target.pathname;
    if (path === '/config.json') return reply(200, { auth: 'local' });
    if (path.startsWith('/api/auth/')) return authReply(request.method, path);
    if (!path.startsWith('/api/')) return reply(404, { error: 'Endpoint not found' });

    const event = buildEvent(request, target);
    try {
      const result = await router.dispatch(event, DEMO_USER_ID);
      const headers = Object.fromEntries(Object.entries(result.headers ?? {}).map(([name, value]) => [name, String(value)]));
      return { status: result.statusCode, headers: { ...headers, 'X-Demo': DEMO_MARKER }, body: result.body };
    } catch (error) {
      console.error(`Demo API error in ${event.requestContext.routeKey}:`, error instanceof Error ? error.name : 'Error');
      return reply(500, { error: 'Internal server error' });
    }
  }

  const send: Send = (method, path, body) => handle({
    method,
    url: path,
    headers: { 'content-type': 'application/json' },
    body: body === undefined ? undefined : JSON.stringify(body),
  });

  async function fresh(): Promise<void> {
    setStore(new MemoryStore());
    await options.seed?.(send);
  }

  await fresh();
  return {
    handles: pathname => pathname === '/config.json' || pathname.startsWith('/api/'),
    handle,
    send,
    reset: fresh,
  };
}
```

```ts
import type { DemoApi } from './api';

export interface FetchHost {
  fetch: typeof fetch;
  location: { origin: string; href: string };
}

// Replaces fetch on the page: same-origin /config.json and /api/* calls are answered by the in-browser API, and everything else
// (the demo's own static files) goes to the original fetch. A request to another origin is never answered locally.
export function installDemoFetch(api: Pick<DemoApi, 'handles' | 'handle'>, host: FetchHost): void {
  const original = host.fetch.bind(host);
  host.fetch = async (input: RequestInfo | URL, init?: RequestInit): Promise<Response> => {
    const raw = typeof input === 'string' ? input : input instanceof URL ? input.href : input.url;
    const target = new URL(raw, host.location.href);
    if (target.origin !== host.location.origin || !api.handles(target.pathname)) return original(input, init);

    const request = new Request(target.href, init ?? (input instanceof Request ? input : undefined));
    const body = request.method === 'GET' || request.method === 'HEAD' ? undefined : await request.text();
    const response = await api.handle({
      method: request.method,
      url: `${target.pathname}${target.search}`,
      headers: Object.fromEntries(request.headers.entries()),
      body,
    });
    return new Response(response.body, { status: response.status, headers: response.headers });
  };
}
```

```ts
import { createStore, referenceNow } from '../../scripts/screenshots/fixtures.mjs';
import type { Send } from './api';

type Reader = (path: string, params?: URLSearchParams) => Record<string, unknown>;

const yearMonth = (date: Date): string => date.toISOString().slice(0, 7);

async function must(send: Send, method: string, path: string, body?: unknown): Promise<Record<string, unknown>> {
  const response = await send(method, path, body);
  if (response.status < 200 || response.status >= 300) {
    // The path is a template-free route; the body is never echoed.
    throw new Error(`Demo seed: ${method} ${path.replace(/[0-9a-f-]{36}/g, '{id}')} answered ${response.status}`);
  }
  return JSON.parse(response.body) as Record<string, unknown>;
}

// Replays the invented household that the About-page screenshots use (scripts/screenshots/fixtures.mjs) as ordinary API
// requests, so the data is valid by construction whenever the data model changes. Nothing here is real.
export async function seedHousehold(send: Send, real: Date = new Date()): Promise<void> {
  const now = referenceNow(real);
  const fixtures = createStore(now);
  const read: Reader = (path, params = new URLSearchParams()) => fixtures.handle('GET', path, params).json as Record<string, unknown>;
  const month = yearMonth(now);
  const from = yearMonth(new Date(Date.UTC(now.getUTCFullYear(), now.getUTCMonth() - 5, 1)));

  // Bills first: the transactions refer to them, and the handlers choose their ids.
  const recurringIds = new Map<string, string>();
  for (const item of read('/api/recurring').recurring as Record<string, unknown>[]) {
    const created = await must(send, 'POST', '/api/recurring', {
      type: item.type, categoryId: item.categoryId, amount: item.amount, description: item.description,
      dayOfMonth: item.dayOfMonth, frequency: item.frequency, anchorDate: item.anchorDate, leadDays: item.leadDays,
    });
    const newId = (created.recurring as { recurringId: string }).recurringId;
    recurringIds.set(String(item.recurringId), newId);
    if (typeof item.handledPeriod === 'string') {
      await must(send, 'POST', `/api/recurring/${newId}/handled`, { period: item.handledPeriod });
    }
  }

  for (const account of read('/api/accounts').accounts as Record<string, unknown>[]) {
    const created = await must(send, 'POST', '/api/accounts', { name: account.name, kind: account.kind, type: account.type });
    const accountId = (created.account as { accountId: string }).accountId;
    for (const balance of account.balances as { date: string; pence: number }[]) {
      await must(send, 'POST', `/api/accounts/${accountId}/balances`, { date: balance.date, pence: balance.pence });
    }
  }

  for (const target of read('/api/targets').targets as Record<string, unknown>[]) {
    await must(send, 'PUT', `/api/targets/${target.categoryId}`, { targetAmount: target.targetAmount, period: target.period });
  }

  for (const pot of read('/api/pots').pots as Record<string, unknown>[]) {
    await must(send, 'PUT', `/api/pots/${pot.categoryId}`, {
      monthlyAmount: pot.monthlyAmount, goalAmount: pot.goalAmount, autoContribute: false, month,
    });
  }

  const range = new URLSearchParams({ from, to: month });
  const transactions = read('/api/transactions/range', range).transactions as Record<string, unknown>[];
  for (const item of transactions.slice().sort((a, b) => String(a.date).localeCompare(String(b.date)))) {
    const mapped = typeof item.recurringId === 'string' ? recurringIds.get(item.recurringId) : undefined;
    await must(send, 'POST', '/api/transactions', {
      amount: item.amount, type: item.type, categoryId: item.categoryId, description: item.description, date: item.date,
      ...(mapped ? { recurringId: mapped } : {}),
    });
  }
}
```

```js
// Builds the browser demo into build/demo/. The dummy Auth0 values only let the build run: the demo never talks to Auth0, and this
// script refuses to run with real values in the environment so a real tenant can never end up in the demo bundle.
const { spawnSync } = require('node:child_process');

const DUMMY = {
  VITE_AUTH0_DOMAIN: 'demo.invalid',
  VITE_AUTH0_CLIENT_ID: 'dummy',
  VITE_AUTH0_AUDIENCE: 'https://demo.invalid/api',
};

for (const [name, value] of Object.entries(DUMMY)) {
  const present = process.env[name];
  if (present && present !== value) {
    console.error(`${name} is set to a different value in this shell. Unset it: the demo build must not use a real tenant.`);
    process.exit(1);
  }
}

const result = spawnSync('yarn', ['react-router', 'build'], {
  stdio: 'inherit',
  env: { ...process.env, ...DUMMY, VITE_DEMO: 'true', BUILD_DIR: 'build/demo' },
});
process.exit(result.status ?? 1);
```
